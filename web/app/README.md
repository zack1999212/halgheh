# Frontend (web/app)

Vite + React app for halgheh. Feature folders mirror the backend services:

- `docs/` – documents UI
- `calendar/` – calendar UI
- `task/` – tasks UI
- `share/` – sharing UI
- `auth/` – login / auth UI
- `workspace/` – workspace layout & shared pages

Each folder will contain its components, pages, and API calls.

## Setup

```bash
cd web/app
npm install
npm run dev      # http://localhost:5173
```

## Build

```bash
npm run build
```
